Help Center & Operations Documentation

Technical and operational documentation for BaliTower Ops: multi-tenant architecture, autonomous workflow authoring, agent tools catalog, and prompt repository.

Multi-Tenant Database Architecture & Analytics Storage
Sistem BaliTower Ops menggunakan basis data tertanam DuckDB (lokasi: data/balitower/inventory.duckdb) untuk memproses mutasi inventaris, SDM, dan keuangan secara cepat. Seluruh data dipartisi secara logis sesuai hak akses divisi (*tenant isolation*).
Pembagian Skema Tenant Operasional

Tiap pengguna dibatasi hanya dapat mengakses tabel dan entitas data sesuai perannya:

Divisi Tenant Akun Pengguna Entitas Tabel Utama
INVENTORY usera (Logistik) inventory_items, stock_balances, purchase_orders, warehouses, suppliers
HR userb (SDM & Field) employees, leave_requests, candidates (Rigger K3), job_postings
FINANCE userc (Keuangan) revenue_invoices, telecom_clients, mla_contracts (Sewa menara), site_land_leases, site_utilities_cost (PLN & genset)
ALL admin (Superadmin) Akses global ke seluruh tabel, audit log transaksi, dan eksekusi instruksi lintas divisi.
Tata Cara Pengelolaan Master Database & Tenant
1

Pilih Domain Operasional

Buka tab Master Database & Tenants, pilih filter divisi: Semua User, Logistik & Material, SDM & Lapangan, atau Keuangan.

2

Pencarian Data Real-Time

Gunakan search bar di pojok kanan atas tabel untuk memfilter baris data instan berdasarkan kode item, NIK karyawan, atau nomor faktur.

3

Penambahan Data Baru (Insert)

Gunakan tombol "Add Material", "Add Employee", atau "Add Invoice" untuk menambahkan rekaman master secara terstruktur.

4

Penyesuaian Saldo Stok & Aksi CRUD

Gunakan tombol "Stock" untuk override saldo rak gudang, atau gunakan tombol "Edit" dan "Delete" untuk mengelola rekaman data.

Mekanisme Penyesuaian Manual Saldo Stok (Admin Stock Override)

Jika terjadi perbedaan fisik antara inventaris aktual di rak gudang dengan catatan DuckDB (akibat audit stock opname atau selisih penerimaan), Administrator dapat melakukan penyesuaian manual langsung melalui tombol aksi pada tabel inventaris di tab Database Master:

1. Saldo Fisik Gudang: Mengubah nilai kuantitas pada tabel stock_balances per gudang (misal: WH-JKT-01, WH-BDG-01).
2. Sinkronisasi Agregat: Kuantitas total pada tabel kompatibilitas items.current_stock otomatis terhitung ulang.
3. Status Stok Otomatis: Sistem langsung mengategorikan item menjadi NORMAL, LOW_STOCK, atau CRITICAL.
Panduan Penyusunan Alur Kerja (Workflow Orchestrator)
Workflow Orchestrator memungkinkan Anda merancang proses bisnis baru tanpa menulis kode. Kompiler AI membaca instruksi bisnis bahasa alami dan mengubahnya menjadi sequence graph eksekusi terstruktur yang langsung aktif di sistem chat.
Langkah-Langkah Membuat Alur Kerja Baru
1

Identitas & Nama Alur Kerja

Isi Nama Alur yang jelas (contoh: Penerimaan Barang Fisik PO & Update Saldo) dan deskripsi tujuan alur.

2

Pilih Tenant Divisi Sasaran

Pilih apakah alur diperuntukkan bagi usera (INVENTORY), userb (HR), userc (FINANCE), atau all (SUPERADMIN).

3

Tulis Aturan Bisnis (Business Instruction)

Tulis prosedur operasional lengkap dalam bahasa Indonesia (kondisi pemicu, penghitungan, dokumen yang diterbitkan, dan email notifikasi).

4

Compile & Simpan Workflow

Klik tombol kompilasi. AI Compiler mem-parsing aturan menjadi langkah eksekusi JSON dan menghasilkan 2-3 contoh pertanyaan otomatis.

5

Aktivasi Instan & Sinkronisasi Bantuan

Alur kerja langsung tersimpan di basis data DuckDB dan muncul pada modal Bantuan Chat pengguna seketika.

Anatomi Graph JSON Alur Kerja

Hasil kompilasi AI menghasilkan struktur eksekusi seperti berikut:

{ "workflow": "pipeline_pengadaan_material_pr_to_po", "version": 1, "steps": [ { "type": "tool", "tool": "inventory.get_low_stock_products" }, { "type": "agent", "task": "calculate_reorder_quantity" }, { "type": "tool", "tool": "docgen.compile" }, { "type": "tool", "tool": "notification.dispatch" } ], "example_prompts": [ "Periksa seluruh stok material yang menipis/kritis dan buat draft PR pengadaan barang dan kirimkan ke email .....@gmail.com" ] }
• type: "tool": Menjalankan fungsi spesifik dari registry tools terdaftar.
• type: "agent": Meminta evaluasi penalaran matematis atau validasi dari model AI.
• example_prompts: Kalimat pertanyaan otomatis untuk memandu pengguna di ruang obrolan.
Tips Menulis Instruksi Bisnis yang Efektif
1. Gunakan Kata Kerja Aksi

Gunakan instruksi terarah seperti: "Periksa saldo stok", "Tarik data karyawan", "Kalkulasi kuantitas", "Terbitkan dokumen PDF", atau "Kirim email otorisasi".

2. Sebutkan Entitas Spesifik

Sebutkan nama entitas yang terlibat: kabel fiber optic, modul rectifier, kontrak sewa menara MLA, surat pesanan PO, permohonan cuti, atau tagihan PLN.

3. Definisikan Status Akhir

Tentukan status data dokumen yang diharapkan, misalnya: "Simpan draft dengan status PENDING_APPROVAL" atau "Ubah status menjadi DELIVERED".

Arsitektur & Mekanisme Kerja Agent Tools
Agent Tools adalah blok fungsi modular (*building blocks*) yang menghubungkan kecerdasan agen LLM dengan basis data DuckDB, generator berkas PDF Typst, dan pengirim email SMTP. Setiap tool memiliki tanggung jawab unik dan validasi skema parameter yang ketat.
Alur Eksekusi Agen Cerdas (Execution Lifecycle)

Alur berurutan bagaimana sistem memproses setiap instruksi pengguna dari input awal hingga dokumen dan balasan selesai:

1
Input Chat Pengguna Penerimaan Permintaan / Trigger
Pengguna mengirim instruksi melalui chat antarmuka atau trigger otomatis multi-tenant.
2
Semantic Router Klasifikasi Intent & Pembatasan Tenant
Mendeteksi tujuan instruksi dan memvalidasi batasan cakupan tenant (usera / userb / userc / admin).
3
Workflow / Plan Resolver Penyusunan Sequence Langkah & Tools
Menentukan urutan langkah kerja otomatis dan memilih tools spesifik yang harus dieksekusi oleh Agen.
4
JSON Execution Engine Validasi Skema & Hak Akses Data
Memvalidasi skema parameter input dan memeriksa izin akses data operasional untuk menjamin keamanan transaksi.
5
Tool Invocation Eksekusi Pipeline Operasional Terpadu
Menjalankan aksi: Query/Update DuckDB ➔ Render berkas PDF Typst ➔ Dispatch Email SMTP notifikasi.
✓
Sintesis Balasan AI Respons Terstruktur & Tautan Unduh
Menyusun respons akhir terstruktur lengkap dengan tautan unduhan dokumen resmi yang siap di-review.
